## 4. The DuckDB file lock

DuckDB allows ONE process to open a database file for writing. To reproduce 'the DuckDB CLI is still
open in another terminal' without the CLI, the builder kept a second process (Python, `duckdb.connect()`)
connected to practice.duckdb while dbt ran. With the real CLI, the message is the same except that
the lock holder is the `duckdb` program (its path and PID appear instead of the Python path).

### dbt run while another process has practice.duckdb open (read-write, like 'duckdb practice.duckdb')

```bash
$ dbt run
```
