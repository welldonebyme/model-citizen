## 1. The legacy model (hard-coded table names, nested and correlated subqueries)

`models/legacy/legacy_monthly_revenue.sql` is pasted unchanged from an old reporting tool. Rule: orders that are
not returned (status not in returned / return_pending), revenue = successful payments, per order month and customer country.

### models/legacy/legacy_monthly_revenue.sql

```bash
$ cat models/legacy/legacy_monthly_revenue.sql
```
```text
-- copied as-is from the old reporting tool: monthly orders and revenue per country
SELECT DATE_TRUNC('month', X.ORDER_DATE) AS ORDER_MONTH, C.COUNTRY,
COUNT(*) AS NUMBER_OF_ORDERS, SUM(X.PAID_CENTS) / 100 AS REVENUE
FROM (SELECT O.ID, O.USER_ID, O.ORDER_DATE,
        COALESCE((SELECT SUM(P.AMOUNT) FROM PRACTICE.STRIPE.PAYMENTS P
                  WHERE P.ORDERID = O.ID AND P.STATUS = 'success'), 0) AS PAID_CENTS
      FROM PRACTICE.JAFFLE_SHOP.ORDERS O
      WHERE O.STATUS NOT IN ('returned', 'return_pending')) X
LEFT JOIN (SELECT ID, COUNTRY FROM PRACTICE.JAFFLE_SHOP.CUSTOMERS) C ON C.ID = X.USER_ID
GROUP BY 1, 2
```

## 2. The refactored, modular version

- `models/intermediate/int_orders__enriched.sql`: one row per order + paid amount + customer country (reusable building block)
- `models/marts/fct_monthly_revenue.sql`: one row per order month and country

### models/intermediate/int_orders__enriched.sql

```bash
$ cat models/intermediate/int_orders__enriched.sql
```
```text
with

orders as (

    select * from {{ ref('stg_jaffle_shop__orders') }}

),

customers as (

    select * from {{ ref('stg_jaffle_shop__customers') }}

),

payments as (

    select * from {{ ref('int_payments__successful') }}

),

order_payments as (

    select
        order_id,
        sum(amount) as paid_amount

    from payments
    group by order_id

),

final as (

    select
        orders.order_id,
        orders.customer_id,
        orders.order_date,
        orders.status,
        orders.loaded_at,
        customers.country,
        coalesce(order_payments.paid_amount, 0) as paid_amount

    from orders
    left join customers
        on orders.customer_id = customers.customer_id
    left join order_payments
        on orders.order_id = order_payments.order_id

)

select * from final
```

### models/marts/fct_monthly_revenue.sql

```bash
$ cat models/marts/fct_monthly_revenue.sql
```
```text
with

orders as (

    select * from {{ ref('int_orders__enriched') }}

),

valid_orders as (

    select * from orders
    where status not in ('returned', 'return_pending')

),

final as (

    select
        cast(date_trunc('month', order_date) as date) as order_month,
        country,
        count(*) as number_of_orders,
        sum(paid_amount) as revenue

    from valid_orders
    group by 1, 2

)

select * from final
```
